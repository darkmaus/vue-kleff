Apply Color Roles:

    Use main (#C73D42) for primary buttons, key call-to-actions, and brand-emphasis elements.

    Use secondary (#E59C6F) for hover states, highlighted icons, and non-primary interactions.

    Use tertiary (#D1636D) for badges, labels, and accent backgrounds that support but do not dominate the main color.

    Use darkGray (#1E1E1E) for text on light backgrounds, headers, and dark UI surfaces.

    Use marble (#ECE9E6) as a base background, card surface, or neutral section separator.

Ensure Visual Contrast:

    Maintain at least AA contrast ratio between foreground (text/buttons) and background colors.

    Example: Text (darkGray) over marble is valid. Avoid using main text on secondary background without testing contrast.

Maintain Visual Hierarchy:

    Limit usage of main color to high-priority actions only.

    secondary and tertiary colors should be used to guide attention subtly.

    Use marble as the default background to keep the layout light and elegant.

Balance Application:

    Do not overuse main and tertiary colors in the same section.

    Pair main with secondary or marble for clean, accessible design.

    When using darkGray as a background, ensure CTA elements (e.g., buttons with main or secondary) are legible and visually distinct.
